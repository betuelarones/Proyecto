Tarjeta de Presentación
Descripción
Este proyecto es una tarjeta de presentación simple creada utilizando tecnologías HTML y CSS. Representa uno de mis primeros proyectos en el desarrollo web, la cuál me permitió aplicar y ejercitar mis  habilidades en HTML y CSS.

Estructura del Proyecto
index.html: Contiene la estructura y el contenido de la tarjeta de presentación.
styles.css: Define los estilos visuales y de diseño para la tarjeta de presentación.

#Contenido de la Tarjeta
La tarjeta de presentación incluye:
Nombre
Habilidades: Las habilidades que vengo aprendiendo.
Enlaces: Enlaces a mis perfiles en redes sociales y/o portafolio en línea.
